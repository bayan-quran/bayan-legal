Politique de confidentialité

Dernière mise à jour : 15 octobre 2026

Bayān est une application iOS de lecture du Coran, d’écoute, d’apprentissage et d’accompagnement (Ustadh).

Responsable et contact

Éditeur de l’application Bayān. Pour exercer vos droits ou poser une question : écrivez à midad.aswad@outlook.fr (voir aussi la page Assistance).

Données collectées

  • Compte (Sign in with Apple) : identifiant Supabase, e-mail (réel ou Hide My Email), prénom fourni par Apple à la première autorisation.
  • Progression / cloud sync : bookmarks, dernière lecture, tentatives Apprendre (LearningMemory), programmes, préférences (dont univers), statistiques liées au compte — lorsque la synchronisation cloud est active.
  • Achats (StoreKit / Apple) : état d’abonnement Premium vérifié côté serveur. Aucune carte bancaire n’est saisie dans Bayān.
  • Ustadh : messages et contexte d’apprentissage limité envoyés uniquement après consentement explicite, et uniquement pour les comptes Premium. Métadonnées techniques (quota, coût, succès) sans texte brut dans le registre d’usage. Historique conversationnel visible : local appareil.
  • Restent sur l’appareil : imports audio, enregistrements micro Apprendre, photos de personnalisation, position pour horaires de prière (non envoyés à un fournisseur IA).

Fournisseurs

  • Apple — AuthenticationServices, StoreKit.
  • Supabase — Auth, Postgres, Edge Functions, synchronisation.
  • OpenAI — traitement Ustadh cloud pour Premium après consentement. Aucune clé dans l’app. Pas de web search / file search / outils cloud payants dans Ustadh V1.

Aucun SDK publicitaire. Pas de tracking ATT. Pas d’analytics tiers ni de crash reporting tiers dans la version actuelle.

Consentement IA

Avant le premier envoi à OpenAI, Bayān affiche une explication et demande Continuer / Pas maintenant. Refus : Quran, écoute et Apprendre restent disponibles ; Ustadh cloud reste indisponible. Retrait possible dans Réglages. Les utilisateurs free utilisent uniquement des capacités locales Ustadh (sans appel IA payant).

Conservation et suppression

Profil → Compte → Supprimer mon compte : suppression des données Bayān liées au compte, nettoyage local, et révocation du jeton Sign in with Apple côté serveur lorsque configuré. Cela n’annule pas un abonnement Apple (à gérer dans les Réglages Apple).

Enfants

Bayān n’est pas destiné aux enfants de moins de 13 ans (ou l’âge minimal applicable).
